01 · What is ALICE

Hard to label, because it is one thing underneath.

Most AI products are built for one job. ALICE (Adaptive Learning Intelligence via Cognitive Engines) starts somewhere else: a general way to hold knowledge, put AI agents to work on it, and keep a record of what they did. AI models supply raw capability; ALICE is what delivers that capability to a course, an office or a laboratory in a form people can use and check.

Each use on this page is the same software under a different configuration. Nothing was rebuilt to move from a calculus course to a technology-transfer office.

Knowledge
Held as linked units of work that people and agents can both navigate.
Agents
Assigned where the work is, configurable, and independent of any one AI vendor.
Record
Who and what produced each result, kept alongside the result.

Application VI

Security

Agents that do not go rogue

Security is built into how ALICE's agents work. They carry out tasks of arbitrary complexity, yet an agent can only take actions from the set approved for it, so a rogue agent has nothing to act with. The same protection holds in every other application on this list.

03 · Agent security

No rogue agents: what an agent can do is decided before it starts.

Most agent security tries to catch bad behaviour after it begins. ALICE removes the opening. An agent composes its work from a fixed vocabulary of actions; the plan can be as long as the task needs, and the vocabulary cannot grow on its own.

A

Fixed vocabulary

Every action an agent may take is enumerated in advance.

B

Composed plan

The agent arranges those actions into a plan for the task at hand.

C

A person approves

The plan is shown in readable form before anything changes.

D

Run and record

The platform carries out the plan and keeps the record.

The common approach

The agent writes and runs its own instructions. Safeguards watch for misbehaviour and try to catch it afterwards.

The ALICE approach

The agent proposes; the platform executes. An action outside the vocabulary has no way to run.

04 · Stewardship

We handle it as a powerful technology.

ALICE was designed with general intelligence in view. A system with that reach can do a great deal of good or a great deal of harm, and we build and release it with both outcomes in mind.

i

Containment first

New capability is added only inside enumerated bounds. Reach never gets ahead of control.

ii

Attribution always

Results carry a record of the people, agents and sources behind them.

iii

Disclosure by agreement

The internals are not published here. Technical briefings are given to funders, partners and institutions under agreement.
